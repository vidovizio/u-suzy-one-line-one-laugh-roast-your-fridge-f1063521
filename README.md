# One Line, One Laugh: Roast Your Fridge

A single-line roast of my fridge — because the only thing colder than its interior is its existential crisis over guarding leftovers I'll never eat. The line targets a specific, recognizable detail (the constant hum, the forgotten Tupperware) and lands a twist: the fridge isn't just running, it's emotionally attached.

## Run it

```bash
node main.ts
# or with custom output directory
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Output appears at `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default).
